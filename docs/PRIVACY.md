# 탑탭 개인정보 안내

탑탭은 현재 화면에서 스크롤 가능한 영역과 위치를 확인하고, 사용자가 상태바를 한 번 누르면 맨 위 이동 또는 터치 스와이프를 실행하기 위해 Android 접근성 API를 사용합니다. 1.2.0은 빠른 이동을 기본으로 사용합니다. 식별한 세로 스크롤 영역에서만 동작하며, 지원하지 않는 화면에 무작정 터치를 보내지 않습니다. 추가적인 호환 스와이프는 선택 기능입니다.

접근성 권한은 화면 구조에 광범위한 접근을 허용합니다. 탑탭은 스크롤 영역, 동작 지원 여부, 현재 앱과 창 식별자, 스크롤 위치를 처리합니다. 최근 스크롤의 위치 정보는 메모리에서만 판단에 사용하며, 화면의 글·사진·입력 내용을 저장하거나 전송하지 않습니다. 인터넷 권한, 광고 SDK, 분석 SDK는 없습니다.

최근 앱의 ‘모두 닫기’ 이후에도 사용할 수 있도록, 사용자가 기능을 켠 동안 Android 포그라운드 서비스를 실행합니다. 실행 상태는 Android의 실행 중인 앱 목록과 알림 정책에 따라 표시됩니다. 일시정지하거나 접근성을 끄면 실행 유지 서비스도 종료합니다. 강제 중지나 시스템의 명시적인 ‘중지’를 우회하지 않습니다. 위치·카메라·마이크·사진·연락처 권한은 요청하지 않습니다.

사용 여부, 스크롤 설정, 제외 앱 목록은 앱 전용 저장소에 보관합니다. 이전 버전의 두 번 터치·영역 너비·표시선 설정은 1.2.0에서 사용하지 않습니다. 백업과 기기 간 설정 전송은 비활성화되어 있으며, 삭제하면 로컬 설정도 삭제됩니다.

접근성은 자동 승인되지 않습니다. 앱의 설명에 동의한 뒤 기기 설정에서 직접 켜야 합니다. 언제든 앱이나 빠른 설정 타일에서 일시정지하거나 Android 접근성 설정에서 권한을 끌 수 있습니다.

디버그 APK는 작동/중지 이유 등의 상태 메시지를 로컬 Android 로그에 남깁니다. 화면 내용이나 입력값은 기록하지 않습니다. QA용 별도 앱과 로컬 테스트 웹페이지는 합성된 스크롤 좌표와 시간을 기록하며, 사용자 배포 APK에 포함되지 않습니다.
