# 탑탭 개인정보 안내

탑탭은 현재 화면에서 스크롤 가능한 영역과 위치를 확인하고 사용자가 상단을 누르면 스크롤 동작을 실행하기 위해 Android 접근성 API를 사용합니다. 호환 스와이프 설정을 켜면 터치 제스처를 실행할 수 있습니다.

접근성 권한은 화면 구조에 광범위한 접근을 허용합니다. 탑탭의 구현은 스크롤 영역, 동작 지원 여부, 현재 앱과 창 식별자, 스크롤 위치만 처리합니다. 화면의 글, 사진, 입력 내용을 저장하거나 전송하지 않습니다. 인터넷 권한, 광고 SDK, 분석 SDK는 없습니다.

사용 여부, 터치 위치·너비, 제외 앱 목록 등 사용자가 지정한 설정은 기기의 앱 전용 저장소에 보관됩니다. 백업과 기기 간 설정 전송을 비활성화하여 다른 기기에서 과거 동의를 자동으로 재사용하지 않도록 구성했습니다. 앱을 삭제하면 로컬 설정도 삭제됩니다.

접근성은 필수 자동 승인되지 않습니다. 앱에서 설명을 확인하고 동의한 뒤 기기 설정에서 직접 켜야 합니다. 언제든 앱에서 일시정지하거나 Android 접근성 설정에서 권한을 끌 수 있습니다.

디버그 테스트 APK는 작동/중지 이유 등의 상태 메시지를 로컬 Android 디버그 로그에 남깁니다. 화면 내용이나 사용자의 입력값은 기록하지 않습니다. 별도 QA fixture는 합성된 테스트 위치를 저장하며 배포 앱에 포함되지 않습니다.
