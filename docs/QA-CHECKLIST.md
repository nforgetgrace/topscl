# 갤럭시 실기기 확인표

자동 테스트 결과는 `VERIFICATION.md`에 별도로 기록합니다. 아래 항목은 삼성 실기기에서 확인하기 위한 목록이며 완료된 것으로 표시하지 않습니다.

- [ ] 사용 기종과 Android / One UI 버전 기록.
- [ ] APK 설치 → 앱의 설명 동의 → 접근성 켜기 → 홈의 실제 연결 상태 확인.
- [ ] 삼성 인터넷 / Chrome의 긴 실제 기사에서 상단 탭으로 맨 위 이동.
- [ ] 삼성 갤러리 사진 목록에서 상단 이동. 개별 사진 확대 화면에서는 의도하지 않은 이동 없음.
- [ ] 자주 쓰는 커뮤니티 / 메신저 / 쇼핑 앱의 목록과 중첩 목록 확인.
- [ ] 왼쪽 / 가운데 / 오른쪽 터치 영역과 디스플레이 카메라 구멍 확인.
- [ ] 영역 바깥에서 알림창과 빠른 설정을 평소처럼 열 수 있는지 확인.
- [ ] 영역 안의 아래 드래그로 알림창(오른쪽은 빠른 설정)이 열리는지 확인.
- [ ] 두 번 누르기, 이동 중 재실행으로 중지, 앱 제외, 빠른 설정 타일.
- [ ] 잠금, 화면 꺼짐, 회전, 앱 전환, 분할 화면, 키보드 표시 상황.
- [ ] 절전 예외 적용 전후와 밤새 대기 후 동작 확인.
- [ ] 재부팅하고 잠금 해제한 뒤 연결 상태 확인.
- [ ] 배터리 절약 모드와 제조사 메모리 정리 후 복구 상태 확인.
- [ ] 사용자 강제 종료·접근성 철회 후 자동 재활성화하지 않고 복구 안내가 나오는지 확인.

## 문제가 생겼을 때 기록할 내용

기종, OS/One UI 버전, 대상 앱과 화면 종류, 터치 위치, 한 번/두 번 누르기 설정, 탑탭 홈의 연결 메시지를 기록합니다. 비밀번호·사진·메시지 등 개인 화면 내용은 수집할 필요가 없습니다.

디버그 APK의 `TopTap` 로그는 실행 상태와 동작 횟수·소요 시간만 보여 줍니다. 지원을 위해 원치 않는 앱 로그 전체를 공유할 필요는 없습니다.
