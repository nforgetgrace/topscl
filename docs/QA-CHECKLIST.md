# 갤럭시 실기기 확인표

이 문서는 자동 통과 기록이 아닙니다. 에뮬레이터에서 확인한 결과는 [VERIFICATION.md](VERIFICATION.md)에 따로 기록합니다. 실기기 검증 때 모델, Android/One UI 버전, 앱 버전, 배터리 설정을 함께 남깁니다.

## 설치와 권한

- [ ] 1.0/1.1 위에 업데이트하고 기존 접근성 연결·제외 앱 설정 유지 확인.
- [ ] 이전 두 번 터치·좁은 영역·표시선·부드러운 모드 꺼짐 설정이 남아 있어도 새 원터치 전체 영역과 빠른 기본값 적용.
- [ ] 최초 설치에서 설명/동의 전 자동 활성화 없음. 접근성 제한 경고와 제한된 설정 허용 경로 확인.
- [ ] Android의 알림 허용/거부 각각에서 실행 유지 상태와 중지 방법 확인.

## 상태바

- [ ] 밝은/어두운 화면에서 활성화 전·대기·터치·스크롤 중 색상선/리플 없음.
- [ ] 시계·중앙·배터리 영역의 위/중간/아래에서 한 번만 눌러 실행. 카메라 구멍처럼 물리적 터치가 불가능한 부분은 제외.
- [ ] 상단 아래 드래그로 알림창, 오른쪽 아래 드래그로 빠른 설정 열기.
- [ ] 긴 누름·가로 드래그·다중 터치로 잘못된 스크롤 없음.
- [ ] 가로/세로, 확대 글자, 표시 크기 변경, 펼침/접힘, 화면 확대 기능과 함께 확인.
- [ ] 전체 화면 영상/게임에서 상태바가 숨겨지면 콘텐츠 터치를 가로채지 않고, 돌아오면 기능 복구.

## 최근 앱 모두 닫기와 복구

- [ ] 탑탭과 다른 앱을 열고 **최근 앱 → 모두 닫기**를 누른 뒤 탑탭 화면을 다시 열지 않고 스크롤.
- [ ] 같은 동작을 10회 반복하고 다른 앱·잠금 해제·화면 회전 뒤에도 확인.
- [ ] 기본 배터리 설정 및 절전 예외 상태에서 각각 확인. 화면 꺼짐, 장시간 대기, 메모리 압박, 재부팅 후 확인.
- [ ] 앱/빠른 설정의 일시정지는 터치 영역과 실행 유지 서비스를 함께 중지. 재개하면 복구.
- [ ] 접근성 해제와 시스템의 명시적인 중지는 즉시 존중하며 자동으로 우회하지 않음.

## 앱별 실제 스크롤

- [ ] 삼성 인터넷과 Chrome의 짧은/긴 문서, 동적으로 추가되는 페이지, 웹 내부 스크롤 패널.
- [ ] 삼성 갤러리의 큰 사진 목록, 날짜 그룹, 앨범, 사진 한 장을 보는 화면.
- [ ] 실제 사용 중 문제가 있었던 앱 이름·화면을 기록하고 각각 재현.
- [ ] 일반 목록, 중첩 목록, 가로 캐러셀과 세로 피드가 섞인 화면, 이미 맨 위인 화면.
- [ ] 한 번 탭의 실제 맨 위 위치, 소요 시간, 화면 녹화의 끊김을 확인. 첫 항목이 조금 잘린 상태를 맨 위로 판정하지 않음.
- [ ] 진행 중 다시 한 번 탭, 사용자 스크롤, 뒤로 가기, 다른 앱으로 전환 시 후속 동작 없음.
- [ ] 접근성을 제공하지 않는 화면에서 잘못된 탭·버튼 실행·가로 이동·값 변경 없음.

## 배포 전

- [ ] 삼성 실기기 결과와 알려진 앱별 제한을 검증 문서에 반영.
- [ ] TalkBack 등 다른 접근성 기능과의 동시 사용 확인.
- [ ] 배포 서명/키 보관, 스토어 접근성·포그라운드 서비스 심사, 실제 개인정보 안내 검토.

현재 설치 파일은 디버그 서명의 테스트 APK입니다. 이 확인표를 작성하지 않은 상태를 ‘모든 경우 검증 완료’ 또는 ‘상용 배포 검증 완료’라고 표현하지 않습니다.
