# 탑탭 1.3.0 검증 기록

검증일: 2026-09-10. [설치 APK](../dist/TopTap-1.3.0-debug.apk) · [결함 조사와 이전 버전 실패](SCROLL-AUDIT.md). 아래는 지정한 에뮬레이터의 결과이며 모든 앱·삼성 실기기·상용 심사 완료를 뜻하지 않습니다.

## 실제 맨 위 도달과 움직임

일반 연속 목록의 최대 위치 샘플 간격 기준은 100ms입니다. 부분 네이티브 이동의 후속 동작 연결은 150ms, 화면 객체가 파괴되는 재생성 사례의 재연결은 600ms 기준으로 별도 검사합니다. 이 둘을 끊김 없는 60fps 통과로 표현하지 않습니다. 원시 좌표는 `motion-emulator-5580-*.json`, `motion-emulator-5582-*.json`에 있습니다. 10,000항목 검사는 20초 설정이며 기본 12초에서의 완료 보장은 아닙니다.

기본 목록·격자의 네이티브 첫 행 애니메이션에는 스와이프를 끼워 넣지 않았음을 별도로 검사합니다. 물리 이동에서는 손을 뗀 후에도 200px 이상 움직이는 관성을 검사합니다.

[1.3.0 실제 화면 녹화](media/toptap-1.3-scroll-demo.mp4)는 350번째 항목에서 한 번 탭 후 첫 행 도착을 별도로 촬영한 것입니다. 위 성능 표는 녹화 부하 없이 측정했습니다. 시작·이동 중·도착 프레임도 확인했습니다.

문서 시작 요청을 즉시 이동으로 처리한 결과는 애니메이션 통과로 세지 않습니다. 좌표는 `chrome-motion-api35/36.json`과 `chrome-motion-api35/36-nested.json`에 있습니다.

## 상태바와 실행 유지

- 가로 5 × 세로 3의 15개 상태바 위치, 가로 화면의 왼쪽·중앙·오른쪽에서 원터치 동작을 확인했습니다. 이전 두 번 터치·좁은 영역·표시선 설정도 함께 검사합니다.
- 기본·밝은 상태바·어두운 상태바에서 기능 끔/대기/스크롤 중 전체 원시 RGBA를 비교했습니다. 각 OS의 실제 높이 128px, 552,960바이트에서 변경 바이트가 0입니다. 시계 분 경계를 피하며 마스킹·보정을 하지 않았습니다. 알림 권한은 거부 상태입니다.
- 실제 최근 앱 화면의 Clear all 버튼으로 제품과 fixture 화면을 닫고, 탑탭을 다시 열지 않고 스크롤했습니다. OS별 3회 반복했으며 포그라운드 서비스 상태도 확인했습니다.
- 프로세스 제거 후 OS 접근성 재연결, 잠금/해제, 제외 앱/일시정지, 권한 해제, 재탭 취소, 앱 전환, 전체 화면, 빠른 설정 타일, 명시적인 시스템 Stop도 각각 검사했습니다. 명시적인 Stop은 전체 앱을 종료합니다.

## UI와 배포 파일

홈·설정·빠른 모드 토글·도움말, 글자 크기 2배의 홈/설정, 가로 설정/도움말, 접근성 설명 대화상자 등 9개 상태를 확인했습니다. 실제 버튼 탐색·설정 저장·동의 취소를 검사합니다. 긴 내용은 스크롤할 수 있습니다.

[홈](screenshots/home.png) · [설정](screenshots/settings.png) · [큰 글자](screenshots/settings-large-text.png) · [가로 화면](screenshots/settings-landscape.png) · [동의 설명](screenshots/disclosure.png)

JDK 21, AGP 9.2.1, Gradle 9.4.1, compile/target SDK 36, min SDK 26입니다. 제품 lint 경고 3개는 SDK/빌드 도구 버전 안내이며, fixture 경고 19개는 테스트 초기화·터치 처리·진단 문자열·백업/아이콘 설정 등에 관한 것입니다. 오류는 0개입니다. Gradle의 향후 10.x 관련 deprecated API 안내가 남아 있습니다.

외부 런타임 의존성, 인터넷·사진·연락처 권한은 없습니다. APK v2 서명과 이전 1.2.0과 동일한 인증서를 확인했습니다. 인증서 SHA-256은 `0fdca0b77e1110241329307a748f70f602279670327e9c819d1426e263c9aee5`입니다. 현재 파일은 업데이트 가능한 디버그 서명 테스트 APK이며 스토어에 게시한 출시 빌드는 아닙니다.

## 재현

```sh
sh scripts/build.sh
python3 scripts/e2e.py --serial emulator-5580 --adb /your/android/sdk/platform-tools/adb
python3 scripts/e2e.py --serial emulator-5582 --adb /your/android/sdk/platform-tools/adb
python3 scripts/e2e.py --serial emulator-5582 --adb /your/android/sdk/platform-tools/adb --only "audit "
python3 scripts/capture-ui.py --serial emulator-5582 --adb /your/android/sdk/platform-tools/adb
# 이전 APK 비교: --apk dist/TopTap-1.2.0-debug.apk --only audit_zero_y
```

1080×2400 ARM64 전용 AVD를 한 대씩 사용했습니다. 개인 기기는 스크립트에서 거부하며 지정한 에뮬레이터의 테스트 설정만 변경합니다. 접근성 서비스 목록은 종료 시 복원합니다. Chrome 최초 실행은 계정 없이 완료된 상태이며 Clear all 좌표는 해당 Pixel Launcher 기준입니다. 테스트 앱·서버·합성 기록은 제품 APK에 포함되지 않습니다.

## 남은 검증

**실제 갤럭시·One UI·사용자가 문제를 겪은 앱 화면은 검증하지 못했습니다.** 삼성 갤러리/인터넷, RecyclerView·Compose·역순 채팅, Android 8~14, 밤새 절전·재부팅·메모리 압박, 폴더블·다중 디스플레이·TalkBack 동시 사용은 추가 검증 범위입니다. [실기기 확인표](QA-CHECKLIST.md)에 기록했습니다.

서로 다른 앱의 스크롤 지원과 자체 애니메이션을 모두 동일하게 강제할 수는 없습니다. 기본 12초/최대 20초 제한 때문에 임의 길이의 모든 화면이 한 번에 끝난다는 보장도 없습니다. 독립 코드/아키텍처 검토는 에이전트 모델 접근 오류로 완료하지 못했으며, 자세한 상태는 [조사 기록](SCROLL-AUDIT.md)에 있습니다. 모든 앱 전수검사·아이폰과 완전히 동일한 움직임·상용 인증 완료로 주장하지 않습니다.
